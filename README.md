# ASA — Homepage prototype

Прототип главной страницы Acoustical Society of America. Три варианта модуля
входа (V1 / V2 / V3) переключаются тумблером в шапке.

**Страница под паролем.** Здесь лежит один файл, зашифрованный AES-256-GCM;
ключ выводится из пароля через PBKDF2-SHA256 (250 000 итераций). Ни пароля, ни
его хеша в репозитории нет — без пароля расшифровать нечего. Расшифровка идёт
целиком в браузере, на сервер ничего не уходит.

Исходники — в приватном репозитории `aip-asa-sources`.
